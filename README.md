## 🚀 À propos de moi

Je conçois et fais évoluer des applications **SaaS B2B en Laravel**, de la base de données jusqu'à l'infrastructure Docker. En alternance chez **Ayctor Labs**, je partage mon temps entre le développement backend et la gestion de projet. Le fil rouge de mes projets récents : intégrer des **LLM auto-hébergés** dans des produits concrets, sans dépendre d'une API tierce.

* 🔭 En ce moment : migration **Laravel 9 → 13** et back-office **Filament**, IA locale avec **Ollama**
* 🔬 Recherche : plateforme d'analyse de conformité de code par IA à l'**ÉTS Montréal**
* 💡 J'aime : le Clean Code, l'automatisation (CI/CD, scraping), optimiser des bases SQL, et corriger un bug proprement côté application plutôt que patcher le vendor
